Conservar páginas completas y la última parcial que pueda sellarse dentro de topes, tipando evidencia incompleta; no añadir eventos ficticios ni truncar un evento para cerrar. Si falla el writer se deja terminar llamada/test y limpieza originales y se detiene entre tests. Si no hay margen para metadata o EOF íntegro, el launcher conserva INVALID_CAPTURE/NOT_RECORDED.
