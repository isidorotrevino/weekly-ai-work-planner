Schema nuevo `d5.typed-operand-projection.v1`, status **OBSERVED_TYPED_PROJECTION**, con root_type/projection_kind, clases permitidas, algoritmo y scope/digest explícitos. No usar OBSERVED_DIGEST como si fuese serialización completa del objeto ni rellenar sha256 ficticio. Los únicos gráficos nuevos previstos son Path escalar, tuple(Path,str), list(Path), clases permitidas y dos excepciones exactas; cualquier otra forma queda NOT_RECORDED con propagación.

La codificación de proyección queda cerrada en `typed_encoding` del JSON: JSON canónico con sort_keys=true, ensure_ascii=true, allow_nan=false y separadores sin espacios.
