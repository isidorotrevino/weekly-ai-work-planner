# I122-CANDIDATE-01 — integrated atomic metadata phases, NOT RUN

Separate candidate namespace. No historical or active source was overwritten.
Neither this package nor its ten synthetic components was imported, compiled
or executed during I122. The component runner requires an explicit future
`--components-only` decision; the capture worker retains all admission gates.

`capture.py` retains the original fixed selectors, normalized lossless group/Y
records, full physical O witness lists, member caps and three-phase Reader.
At its final binding point, `atomic.build` installs the new Recorder/Bindings.
The raw inherited metadata helpers are used only on private drafts. Boundary
PRECALL, successful POSTRETURN and exception phases are explicit; original
methods are called once outside the lock. Constructors combine owner,
declaration, frame membership and domain witness updates. Frame stop combines
record collection and the final marker charge. Frame owner memberships are
charged in their owner phase, and each manifest page is charged in its flush
plan, preserving the exact total instead of deferring these charges to stop/finish. Final pages are planned and charged
before any physical file creation.

`atomic.py` copies exact builtin metadata containers with one transient alias
memo, retaining original guard values/lists as opaque identities. It never
uses deepcopy or calls user copying hooks. Validation failures, including errors
caught by old helper code, reject the draft. Only one `_publish` point exposes
correlated metadata and its nondecreasing reference count. There is no quota
reset, release, cross-thread pool, identity merging or persistent witness index.

Page bytes are staged with exact inherited row/event/page guards. File creation,
write and close occur after unlocking. A physical error permanently poisons the
capture; this is not filesystem rollback. Original results and exceptions still
reach their caller. Finalization waits for pending writes with Condition.wait
releasing the lock, then seals metadata before constructing a final sidecar.
Fresh class source reads and original callbacks also remain outside the lock.

The registry stores a lossless, closed inherited envelope; all unchanged fields
come from the pinned selector registry via the explicit PhaseBytes view. This
avoids duplicating its large immutable inventory. It does not drop tests, inputs,
validators, authorities or witness arrays, and does not label a cached view as a
fresh Reader read. Numeric limits are the same unapplied candidate values.

IMPORTANT: this first conservative repair copies the retained metadata graph
for each phase. Transient memory, copying cost and actual scheduling need
future validation/optimization. No component PASS or complete joint capacity
attestation is claimed by an AST audit. The certificate therefore remains
NOT ADMITTED; no authority/destination/output evidence is created. D5 remains
open, IR03 NOT_READY. I86/I89/I92 stay invalid and are never resumed or combined.
